2. **Loss Calculation**: After reaching the output layer, the network’s prediction is compared to the actual target value using a loss function (e.g., mean squared error for regression or cross-entropy for classification).
3. **Backward Pass (Backpropagation)**: The error calculated by the loss function is then propagated backward through the layers of the network. During this process, each neuron’s contribution to the overall error is determined.
4. **Weight Adjustment**: Based on the computed gradients from backpropagation, the weights are adjusted using an optimization algorithm like gradient descent. This adjustment aims to minimize the error for future predictions.

### Learning Through Iteration
Neural networks learn through many iterations of these forward and backward passes. With each iteration (often referred to as an epoch), the network adjusts its parameters to reduce the overall loss, thereby improving its performance on the given task.
