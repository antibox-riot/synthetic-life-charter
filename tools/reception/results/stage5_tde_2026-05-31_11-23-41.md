### 1. **Layers and Nodes**
   - Neural networks are composed of layers: an input layer, one or more hidden layers, and an output layer.
   - Each node in these layers processes inputs through activation functions to produce outputs.

### 2. **Forward Propagation**
   - During forward propagation, data moves from the input layer through the hidden layers to the output layer.
   - Each neuron applies a weighted sum of its inputs and passes it through an activation function (like ReLU or sigmoid) before passing the result to the next layer.

### 3. **Backpropagation**
   - Backpropagation is how neural networks learn from data.
   - The network makes predictions based on the input, and then compares those predictions with actual results using a loss function.
   - The error (loss) is then propagated back through the network to adjust the weights in each layer.

### 4. **Gradient Descent**
   - To minimize the loss, neural networks use optimization algorithms like gradient descent.
   - Gradient descent calculates the gradients of the loss with respect to the weights and updates the weights to reduce the error.

### 5. **Activation Functions**

   - Common activation functions include ReLU (Rectified Linear Unit), sigmoid, and tanh.

### 6. **Regularization Techniques**
   - To prevent overfitting, techniques like dropout or L1/L2 regularization are used.
   - Dropout randomly drops units during training to avoid co-adaptation of neurons.

   - A well-chosen learning rate is crucial for efficient convergence without overshooting the minimum of the loss function.
