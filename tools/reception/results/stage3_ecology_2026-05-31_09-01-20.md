### Backpropagation

One key method used in training neural networks is called **backpropagation** (short for "backward propagation"). This algorithm enables the network to adjust its weights based on the error it makes during predictions, which helps improve its accuracy over time.

Here's a simplified breakdown of the process:
1. **Forward Pass**: The input data flows through the network layer by layer. Each neuron applies an activation function (like ReLU or sigmoid) to produce an output that is passed to the next layer.
2. **Loss Calculation**: After reaching the final layer, the predicted output is compared with the actual target value using a loss function (such as Mean Squared Error for regression tasks or Cross-Entropy for classification tasks). The difference between these values determines the error.
3. **Backward Pass (Backpropagation)**: The algorithm then computes how much each weight in the network contributed to this error by calculating gradients, essentially determining the direction and magnitude of adjustments needed to reduce the error.
4. **Weight Update**: Using these gradients, weights are adjusted via an optimization method like Stochastic Gradient Descent (SGD) or Adam. This step is where learning occurs; the network updates its parameters based on the errors it made in the previous predictions.

### Adaptive Learning
