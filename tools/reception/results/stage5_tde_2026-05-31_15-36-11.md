1. **Layers and Nodes**: Neural networks consist of layers of nodes (or neurons). The input layer receives the initial data, hidden layers process this data, and the output layer provides the final result or prediction.

2. **Weights and Biases**: Each connection between nodes has an associated weight that determines how strongly one node influences another. Additionally, each node has a bias value which allows for some flexibility in learning from input data.

3. **Forward Propagation**: During forward propagation, data flows through the network from the input layer to the output layer, with each layer processing and passing on its results based on the weights and biases.
