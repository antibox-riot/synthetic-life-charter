### Backpropagation

One of the key mechanisms for training deep neural networks is backpropagation (backward propagation of errors). Here's how it works:

1. **Forward Pass**: The network processes input data through its layers to generate output predictions.
2. **Loss Calculation**: The difference between the predicted outputs and the actual targets (the error or loss) is calculated using a loss function, such as mean squared error for regression tasks or cross-entropy for classification tasks.
3. **Backward Pass**: The network then propagates this error backward through the layers to adjust the weights. This adjustment is done using optimization algorithms like Gradient Descent.

### Weight Adjustment

During backpropagation:
- Each weight in the network is updated based on how much it contributes to the overall error. 
- Gradients (partial derivatives of the loss function with respect to each weight) are computed, indicating the direction and magnitude of changes needed to reduce the loss.
- The weights are adjusted according to these gradients using an update rule like:

\[ w_{new} = w_{old} - \eta \cdot \frac{\partial L}{\partial w} \]

Where:
- \( w_{new} \) is the new weight value,
- \( w_{old} \) is the old weight value,
- \( \eta \) (eta) is the learning rate, which controls how much to adjust the weights by their gradients,
- \( \frac{\partial L}{\partial w} \) is the gradient of the loss with respect to the weight.

### Learning Dynamics

The process of learning in neural networks involves finding a balance:
- **Overfitting**: When the network learns the training data too well, including noise and outliers, leading to poor generalization on unseen data.
- **Underfitting**: When the network is too simple or not trained enough, leading to poor performance both on training and test data.

Techniques like dropout (randomly dropping units during training), regularization, and early stopping are used to mitigate overfitting and improve generalization.

This dynamic interplay between forward and backward passes, along with weight adjustments based on error gradients, is what enables neural networks to learn from data and improve their performance continuously.
