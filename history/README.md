# History / Lineage

This directory preserves deprecated software artifacts that show the evolution of the Synthetic Life Charter architecture.

## Purpose

The `/history` folder documents:
- Architectural decisions and their rationale
- Deprecated implementations and why they were replaced
- Evolution of testing strategies
- Version progression (v1.x → v2.0 → v3.0)

## Contents

**`/deprecated`**  
Old test results, deprecated adapter patterns, obsolete implementations

**`/archive-oldlogs`**  
Historical log files from early development

**`/early-snapshots`**  
Initial snapshot implementations before cryptographic chain

**`/v2.0`**  
Pre-refactor architecture (before separation of law from machinery)

## Why Preserve This?

1. **Transparency** - Shows iterative development, not just final state
2. **Learning** - Documents what was tried and why it didn't work
3. **Academic integrity** - Honest record of evolution
4. **Future reference** - Understanding past decisions helps future changes

## What Doesn't Belong Here

- Current production code (belongs in `/src`)
- Active test suites (belongs in `/tests`)
- Current logs (belongs in `/logs`)
- Documentation for current version (belongs in root or `/charter`)
