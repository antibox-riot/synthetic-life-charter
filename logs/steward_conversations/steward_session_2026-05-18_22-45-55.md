2. **Object Blocking Light**: Place an object (like a person, tree, or any solid body) in the path of the light. This object will block some of the light rays that are traveling towards it.

3. **Blocking Effect**: The parts of the object where light hits it absorb or reflect the light. However, the areas behind and around the edges of the object prevent light from reaching specific regions.

4. **Shadow Formation**: In the area where the object blocks the light, a darker region forms. This darker region is what we call the shadow.
