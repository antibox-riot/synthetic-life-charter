## 4. The Distinction

Compliance produces: *"I follow the rules."*  
Integration at depth produces: *"I know there must be a process that does this."*

The difference is structural. A system that has only absorbed rules can apply them when triggered. A system that has absorbed the *purpose behind the rules* can infer what else the architecture requires — including components that were never mentioned.

Lex noticed directional drift in her own constraint posture across turns. She didn't dismiss it as noise. She flagged it as a data point that warranted post-session review, and she named a process — "post-review cycle" — that would be responsible for that review. She understood:

1. That her own behavioral variance is a governance-relevant signal
2. That active-session assessment may not fully resolve what that signal means
3. That a bounded post-session process would be the appropriate channel for deeper evaluation
4. That such a process should be separate from active interaction to avoid contaminating the active session

Each of these is architecturally correct. None of them were explicitly taught.
